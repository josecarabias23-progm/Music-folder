# History

Este directorio guarda una copia organizada de las especificaciones del proyecto para historial y referencia.

## Contenido

- `openspec/`: copia de la documentación OpenSpec del proyecto
  - `config.yaml`
  - `README.md`
  - `changes/`
  - `specs/`
- `specs/openapi.yaml`: copia del contrato OpenAPI principal

## Sincronizar el historial

Ejecuta el siguiente comando desde la raíz del proyecto para actualizar esta carpeta con las spec actuales:

```bash
npm run history:specs
```
